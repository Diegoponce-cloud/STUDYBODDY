# StudyBuddy — Navigation Flow

| | Registro (inicio) | Perfil del estudiante |
|---|---|---|
| **Purpose** | Permitir que un estudiante cree su cuenta para comenzar a usar StudyBuddy. | Permitir que el estudiante complete su información académica para encontrar compañeros de estudio compatibles. |
| **Information shown** | Nombre completo, correo institucional, contraseña y confirmación de contraseña. | Universidad, carrera, cursos, horarios disponibles y modalidad de estudio. |
| **Actions** | Completar los datos de registro y crear una cuenta. | Completar la información académica y guardar el perfil. |
| **Navigation** | Es la primera pantalla. Crear una cuenta lleva al Perfil del estudiante. | Se llega después de crear una cuenta. Volver regresa a Registro. |
| **Empty / error state** | “Revisa los datos ingresados e intenta nuevamente.” | “Completa tu información para comenzar a encontrar compañeros de estudio.” |
