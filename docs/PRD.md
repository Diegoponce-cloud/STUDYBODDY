# PRD - StudyBuddy MVP

## 1. Resumen
**Producto:** StudyBuddy

**Visión:** Facilitar que estudiantes universitarios encuentren y se unan a grupos de estudio de su mismo curso y con horarios compatibles.

## 2. Problema
Muchos estudiantes necesitan compañeros para estudiar, pero no saben quién cursa las mismas materias o tiene horarios compatibles. Actualmente recurren a WhatsApp, Facebook o contactos personales, lo que hace difícil encontrar compañeros adecuados de forma rápida.

## 3. Solución
StudyBuddy conecta estudiantes según:
- Universidad
- Carrera
- Curso
- Horario
- Modalidad (presencial/virtual)

Los estudiantes pueden crear o unirse a grupos de estudio.

## 4. Usuarios objetivo
- Estudiantes universitarios.
- Estudiantes de institutos técnicos.

## 5. Objetivos del MVP
- Permitir descubrir grupos existentes.
- Permitir unirse fácilmente a un grupo.
- Permitir crear grupos básicos.
- Permitir que cada estudiante complete un perfil con la información necesaria para encontrar compañeros compatibles.

### Embarrassing MVP
> Una aplicación donde un estudiante puede encontrar y unirse a un grupo de estudio de su mismo curso.

## 6. Alcance del MVP

### Incluye
- Registro e inicio de sesión.
- Perfil básico.
- Selección de universidad.
- Selección de cursos.
- Ver grupos existentes.
- Crear grupo.
- Unirse a grupo.

### No incluye
- Chat.
- Videollamadas.
- IA.
- Calendario.
- Compartir archivos.
- Recordatorios.
- Monetización o pagos dentro del MVP.

## 7. Requisitos funcionales
1. Registro de usuario.
2. Completar y editar perfil.
3. Seleccionar universidad.
4. Seleccionar cursos.
5. Listar grupos por curso.
6. Crear grupo.
7. Unirse a grupo.

## 8. Requisitos no funcionales
- Interfaz simple y fácil de entender.
- Respuesta menor a 2 segundos en búsquedas normales.
- Diseño responsive.
- Protección básica de datos.
- Los datos privados del usuario no deben mostrarse en su perfil público.

## 9. Historias de usuario
- Como estudiante quiero registrarme para usar la plataforma.
- Como estudiante quiero indicar mi universidad, carrera y cursos para encontrar grupos relevantes.
- Como estudiante quiero editar mi perfil para mantener actualizada mi información.
- Como estudiante quiero ver grupos disponibles.
- Como estudiante quiero crear un grupo.
- Como estudiante quiero unirme a un grupo existente.

## 10. Criterios de aceptación
- El usuario puede registrarse con datos válidos.
- El sistema rechaza correos duplicados y contraseñas que no coinciden.
- El usuario puede seleccionar universidad y cursos.
- El usuario puede completar y editar su perfil.
- Solo se muestran grupos relacionados con el curso seleccionado.
- El usuario puede crear un grupo.
- El usuario puede unirse a un grupo mientras haya cupo.
- Cuando un grupo está lleno, el sistema informa al usuario y no permite la unión.

## 11. MoSCoW
### Must
- Registro.
- Perfil.
- Buscar grupos.
- Crear grupo.
- Unirse a grupo.

### Should
- Chat.

### Could
- Calendario.
- Recordatorios.

### Won't (MVP)
- IA.
- Videollamadas.
- Compartir archivos.
- Sistema Freemium y pagos.

## 12. Modelo de negocio futuro
El modelo Freemium **no forma parte del MVP**. Se plantea como una opción de negocio para una versión futura.

En una futura versión podría existir:
- **Gratis:** creación limitada de grupos y acceso a grupos.
- **Premium:** grupos ilimitados, prioridad en búsquedas y herramientas adicionales de organización.

## 13. Evolución futura de IA
El nombre del producto es **StudyBuddy**, por lo que el MVP no promete funcionalidades de inteligencia artificial.

En una versión futura, la IA podría recomendar automáticamente compañeros o grupos basándose en universidad, cursos, horarios y preferencias de estudio.

## 14. Perfil público y privacidad
### Información visible en el perfil público
- Nombre.
- Foto de perfil, si el usuario la agrega.
- Universidad.
- Carrera.
- Cursos seleccionados.
- Disponibilidad general de horario.
- Modalidad preferida.

### Información privada
- Contraseña.
- Correo electrónico.
- Número de teléfono.
- Cualquier información personal que no sea necesaria para encontrar compañeros.

## 15. Riesgos
- Bajo riesgo legal y regulatorio para el MVP.
- No procesa pagos en el MVP.
- No requiere permisos especiales.
- Debe evitarse exponer información personal innecesaria.

## 16. Métricas de éxito
- Usuarios registrados.
- Grupos creados.
- Porcentaje de usuarios que se unen a un grupo.
- Retención a 30 días.
